## Mapping 

This code performs the mapping of datasets generated in this study:

1. GSE341565 - Erythroid differentiation Micro-C
3. GSE341752 - STAG2-KO and WT U937 Micro-C
4. GSE341414 - NFE2 and cohesin perturbation Micro-C
5. GSE341753 - NFE2 and cohesin perturbation RNA-Seq

As well as of public datasets (see Table S2 of manuscript.)

Please see each folder for more detail.
