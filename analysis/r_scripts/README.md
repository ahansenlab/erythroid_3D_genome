Description of scripts in this folder:

1. plot_blood_loops_final.Rmd plots the stacked bars in Fig. 2A.
2. deseq_cohesin.R and nfe2_updated.R perform differential expression on RNA-Seq for cohesin factors and the NFE2 TF.
3. genomic_features_matchmakers.R assesses the distrbution by matchmaker cluster of genomic classifications using the ChIPSeeker package (not included in manuscript).
