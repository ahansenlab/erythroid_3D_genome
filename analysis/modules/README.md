
## Analysis modules 

These are modules that are common to many micro-c functions. 

1. ACR computation: runs all the computations of anti-insulation score, crosser loops, etc. 
2. insulation and compartments are just basic functions that multiprocess and streamline from the cooltools docs 
3. matchmaker_functions are a bunch of utils/plotting for the matchmaker analyses to make sure it was consistent between datasets. 
4. looptools_local runs AbLE. Please note that looptools_local.py is written by James Jusuf and is part of the AbLE code (Jusuf et al., NSMB, 2026). This version is the same; I just started this analysis before the repo had been published. 
5. repro runs stats functions and some hicrep stuff 
6. utils is my dump of loop and micro-c convenience functions
