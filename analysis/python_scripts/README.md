This folder contains the following scripts. Please note that most of these scripts run code contained in analysis/modules.

1. microc_merged_analyses.py is a wrapper-type script that runs insulation, compartments, etc.
2. loop_triangle_scores is the main execution script for computing anti-insulation scores (main code is in analysis/modules/acr_computation.py). The "mouse" file is for G1E.
3. print_stats_blood_all.py generates Table S1.
4. run_hicrep.py runs reprodubility analysis.
5. exec_able_blood_v2.py runs loop strength computation.
