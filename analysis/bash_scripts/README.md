This file contains various bash scripts used to compute the following:

1. The H3K4me1 and RAD21 pileups shown in Figs. S4, S8 and S12 of the manuscript (make_mats_ctcf_p12.sh and make_feature_mats_quantiles_xxx)
2. The H3K4me1 and H3K27ac peak signal classifications in Fig. S8 (run_deeptools_enh.sh)
4. Motif enrichments at boundaries in Fig. 1C (run_ame_merged.sh, prepare_ame_files_xx_ and motif_enrichments_xx)
5. Classification commands for eryTF CREs and related track classifications (run_classify_xx)
6. Input preparation for ridge regression in Figs. 3 and S7 (run_matchmodel_inputs.sh)
